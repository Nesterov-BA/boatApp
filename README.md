# boatApp — АСИ: учёт и проверка аварийно-спасательного имущества на судах

Десктоп-программа (PySide6 + SQLAlchemy) для учёта аварийно-спасательного
имущества судов и проведения его периодических проверок с оформлением акта
осмотра и выводом на печать / в PDF. Данные хранятся в SQLite (по умолчанию)
или в базе на сервере — PostgreSQL, MySQL/MariaDB (см. раздел «База данных
на сервере»).

## Возможности

- **Суда** — реестр судов (название, тип, позывной/№, порт приписки, примечания).
- **Имущество** — позиции АСИ на судне: группа, наименование, место хранения,
  требуемое и фактическое количество, единица измерения, срок годности,
  периодичность и дата последнего освидетельствования, примечания.
- **Автоматические статусы** каждой позиции:
  - «В норме», «Дефицит» (фактически меньше требуемого),
  - «Срок годности истёк / скоро истекает»,
  - «Просрочено / скоро освидетельствование» (по дате последней проверки
    и заданной периодичности).
- **Осмотр (акт)** — проведение проверки: по каждой позиции отмечается оценка
  «Годен / Замечание / Не годен», фактическое наличие и комментарий; при
  сохранении акта карточки имущества обновляются автоматически.
- **Журнал актов** — история проверок судна, просмотр, печать, сохранение в PDF
  и HTML (без дополнительных зависимостей — печать средствами Qt).
- **Типовой перечень АСИ** — быстрая загрузка справочного набора позиций
  (жилеты, круги, плот, огнетушители, АРБ/EPIRB, пиротехника, аптечка и др.)
  с последующим редактированием.
- **Демонстрационные данные** — судно с имуществом, наглядными отклонениями
  и примером акта для знакомства с программой.
- Интерфейс на русском языке.

## Установка и запуск

Требуется Python 3.13+ и [uv](https://docs.astral.sh/uv/).

```bash
uv sync                 # установит зависимости в .venv
uv run python main.py   # запуск программы
```

Либо после установки пакета: `uv run boatapp`.

> При первом запуске откроется окно настройки базы данных — выберите локальную
> (SQLite-файл `boatapp.db` в каталоге проекта или свой путь) либо серверную
> СУБД. Настройки сохраняются автоматически; вводить команды в консоли не нужно.
> Путь к локальному файлу можно задать и заранее переменной окружения
> `BOATAPP_DB`, например `BOATAPP_DB=/path/to/data.db uv run python main.py`.

## База данных на сервере (PostgreSQL / MySQL)

Программа умеет работать с базой данных на удалённом сервере. Все таблицы
создаются автоматически при первом подключении — ничего вручную в базе создавать
не нужно.

### Как это работает для пользователя (без консоли)

При **первом запуске** программа сама открывает окно **«Первичная настройка
базы данных»**:

1. Выберите вариант:
   - **Локальная база** — файл SQLite на этом компьютере (путь можно указать
     через «Обзор…»), либо
   - **Серверная база данных** — укажите СУБД (PostgreSQL / MySQL / MariaDB),
     адрес сервера, порт, имя базы, пользователя и пароль.
2. Нажмите **«Проверить и сохранить»**. Программа проверит подключение,
   создаст таблицы и сохранит настройки в файл.
3. Готово — откроется главное окно. При следующих запусках окно настройки
   больше не показывается.

Сменить хранилище позже можно из меню **«Настройки → База данных…»** — так же
без консоли. Если драйвер СУБД не установлен, программа покажет понятное
сообщение с командой для однократной установки.

> Настройки, сохранённые диалогом, — это тот же файл `boatapp.env`
> (см. ниже). Его можно править и вручную.

### Требуется один раз установить драйвер СУБД

```bash
uv sync --extra postgres   # PostgreSQL — драйвер psycopg
uv sync --extra mysql      # MySQL / MariaDB — драйвер pymysql
```

### Альтернатива 1. Файл `boatapp.env` (вручную — то же, что делает диалог)

1. Скопируйте образец в папку проекта/приложения:
   ```bash
   cp boatapp.env.example boatapp.env
   ```
2. Откройте `boatapp.env` и раскомментируйте строку под вашу СУБД, подставив
   логин, пароль, адрес и имя базы:

   ```ini
   # PostgreSQL:
   BOATAPP_DB_URL=postgresql+psycopg://пользователь:пароль@хост:5432/имя_бд

   # MySQL / MariaDB:
   BOATAPP_DB_URL=mysql+pymysql://пользователь:пароль@хост:3306/имя_бд?charset=utf8mb4
   ```

   Файл читается при каждом запуске; пароль нигде не отображается. Если файл
   лежит в другом месте, укажите путь переменной `BOATAPP_ENV_FILE`.

### Альтернатива 2. Переменная окружения (для автоматизации)

```bash
# Linux / macOS
export BOATAPP_DB_URL="postgresql+psycopg://пользователь:пароль@хост:5432/имя_бд"
uv run python main.py

# Windows (PowerShell)
$env:BOATAPP_DB_URL="mysql+pymysql://пользователь:пароль@хост:3306/имя_бд?charset=utf8mb4"
uv run python main.py
```

### Шаги на сервере

1. Установите и запустите СУБД (например, PostgreSQL или MariaDB).
2. Создайте базу данных и пользователя с правами на неё:
   ```sql
   -- PostgreSQL
   CREATE DATABASE boatdb;
   CREATE USER boat WITH PASSWORD 'надёжный_пароль';
   GRANT ALL PRIVILEGES ON DATABASE boatdb TO boat;
   ```
3. Убедитесь, что порт (5432 для PostgreSQL, 3306 для MySQL) открыт для
   компьютера с программой.
4. **Установите драйвер СУБД** в окружение проекта:
   ```bash
   uv sync --extra postgres   # PostgreSQL — драйвер psycopg
   uv sync --extra mysql      # MySQL / MariaDB — драйвер pymysql
   ```
5. Проверьте подключение из терминала (без запуска окна):
   ```bash
   uv run python main.py --check-db
   ```
   При успехе выведется примерно: `Подключение к базе данных установлено:
   диалект: postgresql · сервер: 10.0.0.5:5432/boatdb`.

6. Запустите программу обычным образом. Таблицы создадутся сами.

### Примечания

- Приоритет настроек: аргумент `--db-url` > переменная `BOATAPP_DB_URL` >
  файл `boatapp.env` > `BOATAPP_DB` (путь к SQLite) > `boatapp.db` в проекте.
- Если база недоступна, программа при запуске покажет окно с причиной ошибки
  и подсказкой, какой драйвер установить.
- Одна и та же серверная база может использоваться с нескольких компьютеров —
  данные судов и актов будут общими.
- Таймаут подключения к серверу — 15 секунд, обрывы сети не «подвешивают»
  программу (пул переподключается сам).
- Для PostgreSQL/MySQL драйверы подключаются только по вашей команде — базовые
  зависимости программы их не тянут.

## Структура проекта

```
main.py                  — точка входа
src/boatapp/
  __init__.py            — запуск Qt-приложения
  db.py                  — подключение к БД (SQLite / сервер), сессии, схема
  models.py              — ORM-модели: Ship, EquipmentItem, Inspection, ...
  logic.py               — статусы, сроки, типовой перечень, акты, статистика
  reports.py             — HTML акта, печать и сохранение в PDF
  ui_common.py           — цвета статусов, даты
  dialogs.py             — диалоги судов и позиций имущества
  inspection_ui.py       — форма осмотра, журнал актов, предпросмотр
  main_window.py         — главное окно
```

## Использование

1. На пустом старте нажмите **«Создать судно…»** или **«Загрузить демонстрационные
   данные»**.
2. Выберите судно в верхнем списке. Кнопка **«Типовой перечень АСИ»** добавит
   справочный набор имущества, далее позиции редактируются двойным щелчком.
3. **«Осмотр (акт)…»** открывает форму проверки: отметьте позиции, проставьте
   оценки и фактическое наличие, сохраните акт — откроется предпросмотр, откуда
   акт можно распечатать или сохранить в PDF/HTML.
4. **«Акты / Печать…»** — журнал проверок судна.
5. Кнопка **«Суда…»** открывает список судов (добавление/изменение/удаление).

При удалении позиции имущества строки в ранее оформленных актах сохраняются
(акт хранит «снимок» данных на момент проверки).
